## Members
- Jules Venot
- Amadeo Berthelot

## Topic
A database and web application to manage household waste collection and recycling.

## Project Structure
- `recycling.sql` — database schema and seed data
- `recycling_diagrams.pdf` — entity-relationship and design diagrams
- `waste_types.json` — catalog of waste types (category, recyclability, price, color code)
- `treatment_centers.json` — recycling and treatment centers
- `collection_points.json` — collection points (bins, drop-off locations)
- `collections.json` — collection operations (date, vehicle, driver, status)
- `waste_collection.json` — quantities of waste collected per operation
