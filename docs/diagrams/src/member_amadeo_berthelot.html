Annotations

1Shared navbar; the current section (Collections) is highlighted.
2Read-only facts of the collection row. Point and center are links to their own datasheets (FK point_id, center_id).
3Status buttons follow the ENUM: planned → in_progress → completed, or cancelled when the point is inaccessible (UC-B steps 2, 5 and extension).
4One row per collection_waste line (JOIN with waste_type for the label and colour). Each line can be edited or removed.
5Inline “add line” row: waste type, sorted yes/no, quantity in kg. The total is recalculated after each change (SUM of quantity_kg).
6Inline error message, no pop-up: duplicate waste type (PK collection_id + waste_type_id, flow 3a) or empty / negative quantity (flow 3b).
Legend
Dark button = main action · dashed border = exceptional action / message · ▾ = drop-down · ☐ = checkbox · hatched area = header picture.

sequenceDiagram
  autonumber
  actor D as Driver
  participant V as CollectionView<br/>(Vue page)
  participant R as Express router
  participant C as CollectionWaste<br/>Controller
  participant Repo as CollectionWaste<br/>Repository
  participant DB as MySQL<br/>(recycling)

  D->>+V: choose waste type, kg, sorted<br/>and click "Add line"
  V->>V: validate() – type chosen, kg > 0
  V->>+R: fetch POST /api/collections/7/waste<br/>(waste_type_id, quantity_kg, is_sorted)
  R->>+C: addWasteLine(req, res)
  deactivate R
  C->>+Repo: await insertLine(7, line)
  Repo->>+DB: INSERT INTO collection_waste<br/>VALUES (?, ?, ?, ?)

  alt insert succeeded
    DB-->>Repo: affectedRows = 1
    Repo-->>C: true
    C-->>V: 201 Created + saved line (JSON)
    V->>V: push line, recompute total
    V-->>D: new row and updated total shown
  else duplicate key (collection_id, waste_type_id) – flow 3a
    DB-->>Repo: error ER_DUP_ENTRY
    Repo-->>C: throw DuplicateLineError
    C-->>V: 409 Conflict + message
    V-->>D: inline error "already recorded,<br/>edit the existing line"
  end
  deactivate DB
  deactivate Repo
  deactivate C
  deactivate V

  Note over C,DB: The database refuses the duplicate itself:<br/>composite primary key of collection_waste
