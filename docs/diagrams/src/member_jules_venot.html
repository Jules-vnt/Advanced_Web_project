Annotations

1Shared navbar; the current section (Collections) is highlighted. The “New collection” button on top of the list opens this blank form.
2Date picker: the date must be today or later, otherwise the form is refused (flow 5a). The status is fixed to planned for a new collection (ENUM default).
3Drop-down filled from collection_point (name + city). Choosing a point pre-selects its center from collection_point.center_id (step 4). Only active centers (is_active) are listed.
4Driver chosen among the users with role driver in app_user; stored with the plate in collection.driver_name and vehicle_plate.
5Flow 4a: the point has no center (FK ON DELETE SET NULL) → inline error, the manager picks an active center manually.
6Flow 5b: the driver already has a collection that day → warning, not a blocking error. Submit sends POST /api/collections; Cancel goes back without saving.

sequenceDiagram
  autonumber
  actor M as Manager
  participant V as CollectionFormView<br/>(Vue page)
  participant R as Express router
  participant C as Collection<br/>Controller
  participant Repo as Collection<br/>Repository
  participant DB as MySQL<br/>(recycling)

  M->>+V: fill date, point, center, driver,<br/>plate and click "Submit"
  V->>V: validate() – fields filled, date ≥ today
  V->>+R: fetch POST /api/collections<br/>(point_id, center_id, collection_date,<br/>driver_name, vehicle_plate)
  R->>+C: createCollection(req, res)
  deactivate R
  C->>+Repo: await isDriverBooked(driver, date)
  Repo->>+DB: SELECT COUNT(*) FROM collection<br/>WHERE driver_name = ? AND collection_date = ?
  DB-->>-Repo: count
  Repo-->>-C: true / false

  alt driver free that day
    C->>+Repo: await insertCollection(data)
    Repo->>+DB: INSERT INTO collection<br/>VALUES (?, ?, ?, ?, ?, 'planned')
    DB-->>-Repo: insertId = 11
    Repo-->>-C: 11
    C-->>V: 201 Created + new collection (JSON)
    V-->>M: datasheet of the new collection<br/>with status "Planned"
  else driver already booked that day – flow 5b
    C-->>V: 409 Conflict "driver already<br/>booked that day"
    V-->>M: inline warning: confirm anyway<br/>or choose another driver
  end
  deactivate C
  deactivate V

  Note over C,DB: No UNIQUE key on (driver_name, collection_date):<br/>the controller checks it with a SELECT before the INSERT.<br/>If the manager confirms, Vue sends the POST again with confirm = true.
