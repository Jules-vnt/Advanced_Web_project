Annotations

1Toolbar: counter, filter on the point_type ENUM (street_bin, drop_off_center, container, business) and the main action “New collection point”.
2One row per collection_point. The center name comes from the FK center_id (JOIN with treatment_center), “—” if none.
3Map link built from latitude / longitude, opens OpenStreetMap in a new tab.
4Shared Show / Edit / Delete buttons. Delete asks for confirmation: the linked collections are deleted too (ON DELETE CASCADE).
5Form with the table columns: name, type, address, city, latitude, longitude, treatment center (drop-down of active centers only).
6“Save” checks the fields first; errors are shown inline under each field, no pop-up. On success → POST / PUT, then back to the list.
Legend
Dark button = main action · dashed border = destructive action / invalid field · ▾ = drop-down · ⌖ = map link · hatched area = header picture.

sequenceDiagram
  autonumber
  actor M as Manager
  participant V as TreatmentCenterFormView<br/>(Vue page)
  participant R as Express router
  participant C as TreatmentCenter<br/>Controller
  participant Repo as TreatmentCenter<br/>Repository
  participant DB as MySQL<br/>(recycling)

  M->>+V: change capacity / address / active<br/>and click "Save"
  V->>V: validate() – name, city filled, capacity ≥ 0
  V->>+R: fetch PUT /api/treatment-centers/5<br/>(name, city, address, capacity_tons, opening_date, is_active)
  R->>+C: updateCenter(req, res)
  deactivate R

  alt valid data
    C->>+Repo: await updateOne(5, center)
    Repo->>+DB: UPDATE treatment_center SET name = ?, city = ?, …<br/>WHERE center_id = ?
    alt row found
      DB-->>Repo: affectedRows = 1
      Repo-->>C: 1
      C-->>V: 200 OK + updated center (JSON)
      V-->>M: redirect to /treatment-centers/5<br/>with saved values
    else no row with this id
      DB-->>Repo: affectedRows = 0
      Repo-->>C: 0
      C-->>V: 404 Not Found
      V-->>M: "There is no treatment center with the ID 5"
    end
    deactivate DB
    deactivate Repo
  else invalid data (empty name, capacity < 0)
    C-->>V: 400 Bad Request + error list
    V-->>M: inline errors under the fields
  end
  deactivate C
  deactivate V

  Note over C,DB: Placeholders (?) = prepared statement,<br/>the id comes from req.params.id
